A las señales les aplicamos un notch de 50Hz (para sacar el ruido de línea) y les restamos el promedio de los primeros 2 segundos para corregir el offset de base.
Armamos gráficos interactivos donde se superponen las dos mediciones de cada músculo (la del canal A y la del canal B), para las 5 vocales. La idea es: si el músculo se comporta igual sin importar el canal, las dos curvas se tienen que parecer. Si una sale muy distinta o rota, el problema es del canal, no del músculo.
